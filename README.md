# Lista 💚

**Ilista mo na.** A simple, friendly expense + utang tracker for Android and iPhone.

- 💸 Log expenses and income in seconds (GCash, Maya, cash, card, bank)
- 🤝 Track utang: who owes you and who you owe, with partial payments
- ⏰ Due-date reminders and an optional daily 8 PM nudge
- 📊 Monthly reports: category donut, day-by-day chart, compare vs last month
- 🌙 Light and dark mode · data stays on your phone (SQLite)

## iPhone (and any phone)

Open **https://harbspacamarra2-max.github.io/lista-app/** in Safari, tap **Share → Add to Home Screen**.

## Get the APK

Every push to `main` builds a new APK automatically.
Open the **Releases** section of this repo (or `/releases/latest`) and download **Lista.apk**.

## Run it yourself (on a computer)

```bash
npm install
npx expo start
```

Built with Expo (React Native), Expo Router and expo-sqlite.
